# 选代理服务之前，先把问题说清楚

有人想看流媒体，有人是客户端装不上，还有人已经连上了，却不知道网页为什么还是打不开。这些问题都可能被归到“加速器”下面，但解决办法不一样。先弄清自己要用什么设备、准备访问什么服务，以及真正卡在哪一步，再去看套餐和下载入口，通常比先找一份“哪个好用”的名单更靠谱。

这里放的是公开资料、页面入口和排查思路。没有做过真实线路测试的服务，不会写成亲测；页面宣传的速度、稳定性或平台支持，也不会在这里被当作结论。

如果连自己需要的是 VPN、游戏加速器还是 Wi-Fi 调整都还没想清楚，可以先看《[网络加速器有哪些类型？先分清 VPN、游戏加速器和 Wi-Fi 优化](guides/network-accelerator-types.md)》。它从实际问题出发，解释三类工具各自能处理什么，也提醒下载页的跳转不能代替安装包核验。

如果眼下最担心的是下载来源，可以从《[网络加速器下载官网怎么核对？先确认入口、设备和安装来源](guides/network-accelerator-download-official-site.md)》开始。它把介绍页、下载按钮和实际跳转地址分开看，也记录了五个推广关联页面当时显示的名称。客户端和安装包本身没有测试。

Netflix 播放时遇到缓冲、画质上不去，或者设备没有出现 4K 选项，《[奈飞高速节点怎么选？Netflix 4K 网速要求与卡顿排查指南](guides/netflix-high-speed-nodes.md)》会更有用。文中依据 Netflix 的公开说明整理检查顺序，不把它写成节点测速报告。

已经拿到某个客户端入口，但还在核对设备支持、下载页跳转或连接问题时，可以看《[老王加速器下载与使用指南](guides/laowang-accelerator-guide.md)》。这篇只记录网页当时的展示和跳转，没有测试客户端、节点或套餐。

## 点下载之前，多看一眼

网页能打开，不等于安装包可信；页面说支持某个设备，也不代表你的系统版本一定适配。涉及下载、付款或长期套餐时，先核对介绍页、下载页和安装包发布者是否一致，再去看有效期、流量、设备数、自动续费和退款规则。网络表现还会受本地运营商、设备、Wi-Fi 和使用时段影响，宣传页上的数字代替不了自己的测试。
